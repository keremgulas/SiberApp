#  SiberApp - Android APK Statik Güvenlik Analizörü

**SiberApp**, Android uygulamalarının (`.apk`) talep ettiği izinleri inceleyerek statik güvenlik analizleri gerçekleştiren ve potansiyel risk durumlarını değerlendiren bir güvenlik aracıdır.

---

##  Özellikler

-  **APK İzin Analizi:** Android uygulamalarının sistemden talep ettiği izinleri tarar.
-  **Risk Değerlendirmesi:** Tehlikeli olarak sınıflandırılan izinleri tespit eder ve güvenlik risk skorunu hesaplar.
-  **Statik Analiz Yaklaşımı:** Uygulamayı çalıştırmaya gerek kalmadan kaynak kod ve manifest yapılarını inceler.
-  **Kullanıcı Dostu Arayüz:** Jetpack Compose ile tasarlanmış modern Android arayüzü.

---

## Kullanılan Teknolojiler

- **Dil:** Kotlin
- **Arayüz (UI):** Jetpack Compose
- **Platform:** Android SDK
- **Geliştirme Ortamı:** Android Studio
